## Deferred recognition acceptance criteria and limitations

The curated 20/20 development set is structurally valid, but 31 new candidate labels remain unreviewed and unscored by user choice. There is no frozen held-out set with at least 50 target-present and 50 target-absent views. Prompt wording materially changes outcomes: `red mat` recovered three severe-occlusion positives missed by `red floor mat`, though one ~24%-visible view remains missed and the three recoveries scored close to the 0.5 confidence threshold. The accepted development evidence (eight positives, one negative) is too small to establish recognition acceptance. Exact duplicate captures were found and excluded, confirming the need for hash-based independence checks. Lighting pixels demonstrably change and one dim positive was detected, but one image per profile cannot characterize robustness. The direct-pose path works for translated and rotated captures; broader condition coverage remains open. The planned ≥95% recall, median IoU ≥0.70, and ≤5% negative-frame false-positive gates remain **unmeasured and waived only for advancing this demo to Phase 3**. The candidate prompt `red mat` at threshold 0.5 is provisional, not frozen. Phase 3 is authorized in inference-only mode to validate the runtime pipeline; no model output may affect navigation.
